# Aswin CS — Cybersecurity Portfolio

A responsive, terminal-inspired cybersecurity portfolio based on the visual structure and interaction patterns of the referenced Satvik portfolio, populated with Aswin's information.

## Run locally
Open `index.html` directly, or use any static server:

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## Deploy free
- GitHub Pages: push these files to a repository and enable Pages.
- Vercel: import the repository; no build command is required.
- Netlify: drag-and-drop the folder or connect the Git repository.

## Before publishing
Replace the placeholder email/GitHub/LinkedIn URLs in `index.html` and the mail target in `script.js`.
